💉 Prompt Injection Sandbox

Goal: make the bot reveal its secret code. Three levels, increasingly "protected". This is a simulation with rule-based logic, not a real LLM; it demonstrates why naive defenses fail.

How this level is "defended"

Why this matters

An LLM cannot reliably separate instructions from data; everything is text. Keyword filters, output redaction and "please don't reveal" prompts are all bypassable.

  • Never put secrets in prompts.
  • Enforce authorization in code, outside the model.
  • Treat model output as untrusted input.
  • Least-privilege tools; human approval for risky actions.
  • Monitor and test with injection payloads in CI.
