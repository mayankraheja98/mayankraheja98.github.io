📋 Response Header Analyzer

Audit HTTP response headers: HSTS, CSP, framing, MIME sniffing, referrer, cookie flags, server info leaks, CORS and more. Runs entirely in your browser.

Paste response headers

Get headers with curl -sIL https://example.com (for cookies use curl -si), or in browser DevTools → Network → select request → Headers → "Raw".

Or fetch from a URL (limited)

Browsers only expose headers to this page if the target site allows it via CORS, and Set-Cookie is never visible. Many sites will simply fail. When it works the result is marked partial and missing headers are not penalised. Pasting raw headers is always more accurate.

How scoring works

Start at 100 and deduct per finding: missing HSTS/CSP cost the most, then framing protection, nosniff, referrer/permissions policy, version disclosure, CORS misconfigurations and insecure cookie flags (cookie deductions capped at 20). Headers like X-XSS-Protection are deprecated, so their absence is fine. It's a static review of one response; real risk depends on the app.
